### Haqqımda

Mən **proqram mühəndisiyəm və Minnesota Universitetində Kompüter Elmləri üzrə magistr təhsili alıram**. Python, TypeScript, C# və C++ ilə veb tətbiqləri hazırlayır, süni intellekt xidmətlərini inteqrasiya edir və interaktiv sistemlər qururam.

İşim **verilənlərin vizuallaşdırılması, səs əsaslı süni intellekt, kompüter qrafikası və VR/XR** sahələrini əhatə edir. İstifadəçi interfeysini, API-ləri və alqoritmləri birləşdirməyi, prototipi işlək tətbiqə çevirmək üçün problemləri həll etməyi sevirəm.

Hazırda **IPMD, Inc.** şirkətində proqram mühəndisliyi üzrə təcrübəçiyəm (sentyabr 2026–hazırda). Eyni zamanda **Prof. Victoria Interrante** ilə avatar realizmi və VR-də stress mövzusunda magistr dissertasiyası üzərində işləyirəm (yanvar 2026–hazırda).

*Gözlənilən məzuniyyət: dekabr 2026 · GPA 3.8/4.0 · Azərbaycan Dövlət Təqaüd Proqramı ilə maliyyələşdirilir.*
